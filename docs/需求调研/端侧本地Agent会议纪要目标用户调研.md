# 端侧本地 Agent 会议纪要目标用户调研

- **产品方向**：将端侧本地 Agent 会议纪要能力集成到投影设备
- **核心价值**：会议音频、转写、总结和任务提取均在本地完成，敏感内容不上传云端
- **调研日期**：2026-08-12

## 一、目标用户结论

首批目标用户应为：

> 有固定会议室、会议频率高、内容具有内部保密性、允许经授权录音，并且不希望音频上传云端的中型企业和组织。

建议优先从**制造业、研发和工程设计企业的内部项目会议**切入，而不是首先面向家庭用户或普通教育市场。

## 二、核心目标客户画像（ICP）

### 组织画像

- 企业规模：50～500 人
- 所属行业：制造、研发、工程、工业设计等
- 会议环境：配有投影设备的固定会议室
- 会议人数：3～15 人
- 使用频率：每周多次项目或管理会议
- 安全要求：不希望会议原始音频及纪要上传第三方云端
- 使用条件：内部会议经过授权后可以录音

### 典型会议场景

- 项目评审和项目周例会
- 研发设计评审
- 质量、生产和供应链会议
- 客户需求与方案评审
- 分支机构内部管理会议
- 招投标、合同及技术方案讨论

## 三、用户角色与核心诉求

| 角色 | 典型人群 | 核心诉求 |
|---|---|---|
| 实际使用者 | 项目经理、部门负责人、会议主持人、秘书或助理 | 自动生成结论、待办和责任人，减少手工记录 |
| 购买决策者 | 行政、IT、信息化负责人、会议室管理者 | 不依赖云服务、容易部署、降低会议管理成本 |
| 安全把关者 | 信息安全、法务、合规部门 | 音频和纪要不出设备，权限、删除和审计可控 |
| 最终受益者 | 所有参会人员 | 会后明确谁在什么时间前完成什么任务 |

产品的主要付费主体应是**企业、组织或业务部门**，而不是单个参会人员。

## 四、目标市场优先级

| 优先级 | 目标市场 | 适配度 | 主要原因 |
|---|---|---:|---|
| P0 | 制造业、研发、工程和工业设计企业 | ★★★★★ | 投影会议室普及、会议频繁、技术资料敏感，采购链路相对可控 |
| P1 | 央国企、政府部门、金融、法律和医疗机构 | ★★★★★ | 保密需求强，愿意为本地化付费，但安全认证要求高、采购周期长 |
| P1 | 大型企业的研发、法务和战略等敏感部门 | ★★★★☆ | 需求明确，但可能已有会议平台，需要证明本地方案的差异化价值 |
| P2 | 教育、培训和咨询机构 | ★★★☆☆ | 有内容整理需求，但保密性通常不是主要购买理由 |
| P3 | 家庭用户和普通消费者 | ★☆☆☆☆ | 会议频率低，手机或云端应用通常能够满足需求 |
| 暂不优先 | 超大会议、公开论坛和复杂跨语言会议 | ★★☆☆☆ | 对拾音、算力、多人识别、实时性和稳定性要求较高 |

## 五、首批客户选择原则

首批客户应满足以下条件：

1. 会议内容敏感，确实存在“不愿上云”的问题；
2. 经参会人员授权后允许录音；
3. 有固定会议室和稳定的使用频率；
4. 对会议结论、待办和责任人有明确管理需求；
5. IT 或行政部门能够推动试点采购；
6. 不要求首版产品立即达到国家涉密设备标准。

不建议首版直接进入最高保密等级市场。部分政府、军工、董事会或涉密项目会议可能并非“不允许上云”，而是**完全不允许录音**。此类场景还可能要求：

- 设备及软件安全认证
- 物理隔离或专用网络
- 完整权限和审计机制
- 私有化升级与运维
- 录音授权和操作留痕
- 更长的采购及验收周期

因此，首批更适合选择：

> 内容敏感，但经过授权可以录音的企业内部会议。

## 六、投影设备的差异化价值

如果产品只是将“录音转写和自动总结”装入投影机，与手机、电脑软件相比差异化不足。

投影设备应发挥会议现场公共屏幕和会议中枢的价值：

1. **会前**：展示议程、参会人员和上次会议待办；
2. **会中**：本地识别关键结论、决策、问题和待办事项；
3. **会尾**：将结论、责任人和截止时间投到屏幕上；
4. **现场确认**：主持人与参会人员共同核对、修改和确认；
5. **会后**：在本地生成正式纪要，通过受控方式导出。

建议产品定位为：

> 本地化的智能会议室中枢，而不只是投影机内置的录音转写功能。

## 七、建议产品形态

如果投影机本体缺少满足会议要求的阵列麦克风，建议采用：

> 投影主机 + 桌面麦克风或阵列拾音器 + 本地会议 Agent

首版优先支持：

- 3～15 人小型固定会议室
- 普通话为主的内部会议
- 会议时间 30～120 分钟
- 固定座位或相对稳定的发言距离
- 项目例会、评审会和管理会议

应避免首版覆盖超大会议室、远距离拾音、多人同时讲话和高度复杂的跨语言会议，以免拾音和识别问题影响整体产品评价。

## 八、首版必须具备的保密与信任能力

- 默认本地运行，不上传云端
- 无网络条件下仍可完成核心功能
- 物理麦克风静音键
- 清晰、持续可见的录音状态指示
- 会议开始前的录音授权提示
- 音频、转写文本和纪要本地加密存储
- 管理员、主持人和普通用户的权限划分
- 可设置自动删除周期
- 支持单场会议立即彻底删除
- 受控 USB 或企业局域网导出
- 操作日志和导出审计
- 企业人名、产品名和技术术语词库
- 会议结束前由主持人确认纪要

## 九、建议的首版产品定位

> 面向研发和制造企业的离线智能会议投影系统：会议音频、转写和纪要全部在本地完成，帮助团队现场确认决策与待办，让敏感内容不离开会议室。

## 十、建议优先验证的客户与人员

### 优先拜访企业

- 中型制造企业
- 软硬件研发企业
- 工程设计企业
- 工业自动化企业
- 有自主研发部门的设备厂商

### 优先访谈人员

1. 项目经理或研发负责人：验证会议纪要和待办管理价值；
2. 行政或会议室负责人：验证部署、使用和采购流程；
3. IT 负责人：验证设备接入、维护和局域网导出需求；
4. 信息安全负责人：验证本地处理、权限、审计和删除要求；
5. 普通参会人员：验证录音接受度和实际使用体验。

## 十一、用户调研重点问题

### 会议现状

- 每周召开多少次需要形成纪要的会议？
- 单次会议通常有多少人、持续多长时间？
- 当前由谁记录和整理会议纪要？
- 从会议结束到纪要发出通常需要多久？
- 最容易遗漏的是结论、责任人还是截止时间？

### 保密需求

- 哪些会议内容不能上传外部云服务？
- 企业是否允许在内部会议中录音？需要谁授权？
- 会议资料允许保存多久？
- 是否要求原始录音、转写文本和最终纪要分别设置保存策略？
- USB、局域网、二维码等导出方式中，哪些可以被接受？

### 产品体验

- 是否需要实时字幕，还是会后纪要即可？
- 是否需要区分不同发言人？
- 是否愿意在会议结束前用 1～3 分钟确认结论和待办？
- 最希望自动生成哪些内容：摘要、决策、问题、待办、责任人或截止时间？
- 投影屏幕上实时显示内容是否会干扰会议？

### 采购与部署

- 该产品应由行政、IT、业务部门还是信息安全部门采购？
- 更倾向购买新投影设备，还是给现有投影增加智能会议模块？
- 能否接受独立桌面拾音设备？
- 对单间会议室的可接受价格是多少？
- 需要哪些认证、接口和售后服务才能进入采购流程？

## 十二、阶段性判断

当前最值得优先验证的客户群为：

> 中型制造、研发和工程企业中，负责项目会议的项目经理，以及负责会议室、IT 和信息安全的相关负责人。

产品需求成立需要同时验证三个条件：

1. **效率价值**：自动纪要能够显著减少整理时间并提高待办执行率；
2. **隐私价值**：本地处理确实能解决客户不愿使用云端方案的问题；
3. **设备价值**：集成到投影及会议室，而不是单独使用电脑或手机，能够带来更好的现场协同和采购理由。
