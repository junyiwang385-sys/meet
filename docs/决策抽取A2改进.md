# 决策抽取改进(A2:提回主链路 + 收紧判定)

> 决策从 enrichment 增强层提回主链路(`summary.decisions`),独立调用(保专用注意力)、复用 A 层语义块、
> 喂 block 已抽 key_points 当锚、收紧 decision/proposal 判定。2026-09-17。

## 动机(架构割裂 + over 过高)
原方案 `enrichment.extract_decisions`:①决策在增强层、summary.decisions 空;②按 50 段硬切(切断决定);
③从零读原文;④**type 不区分**(整集当决定);⑤决策散在 key_points/action_candidates/enrichment 三处。
→ over_decision=5/场、噪声大。

## A2 做法(`stages/product_summary.py`)
- `_decision_messages`:块 Timeline + key_points 锚 + **收紧判定**(明确拍板才 decision,拿不准记 proposal);
- `_validate_decisions`:refs 锚本段、owner 无据置 null、type 归一;
- 块级循环(复用 A 层块,某块失败优雅降级)+ `_dedup_decisions`(跨块近似去重,decision 优先);
- `validate_summary_object` 后回填 `summary["decisions"]`(保住 type,不动 validation)。

## 回归(g1-g5,n=5,opus 判)
