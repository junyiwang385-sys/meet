# 决策抽取改进(A2:提回主链路 + 收紧判定)

> 决策从 enrichment 增强层提回主链路(`summary.decisions`),独立调用(保专用注意力)、复用 A 层语义块、
> 喂 block 已抽 key_points 当锚、收紧 decision/proposal 判定。2026-09-17。

## 动机(架构割裂 + over 过高)
原方案 `enrichment.extract_decisions`:①决策在增强层、summary.decisions 空;②按 50 段硬切(切断决定);
③从零读原文;④**type 不区分**(整集当决定);⑤决策散在 key_points/action_candidates/enrichment 三处。
→ over_decision=5/场、噪声大。

## A2 做法(`stages/product_summary.py`)
- `_decision_messages`:块 Timeline + key_points 锚 + **收紧判定**(明确拍板才 decision,拿不准记 proposal);
- `_validate_decisions`:refs 锚本段、owner 无据置 null、type 归一;
- 块级循环(复用 A 层块,某块失败优雅降级)+ `_dedup_decisions`(跨块近似去重,decision 优先);
- `validate_summary_object` 后回填 `summary["decisions"]`(保住 type,不动 validation)。

## 回归(g1-g5,n=5,opus 判)
| 指标 | A2 | 原方案 | 结论 |
|---|---|---|---|
| over_decision | **0.067** | 0.556 | A2 压低 ~8×(治卖点) |
| decision/proposal 区分 | ✅ | ❌ type 全空 | A2 修本质缺陷 |
| 噪声 | 0.361 | 0.417 | A2 略低 |
| 决策覆盖 | 0.514 | 0.686 | A2 -17pp(收紧代价) |

**结论:采纳 A2**(over 大幅降 + 能区分 proposal + 降噪声);**待优化**:微调收紧度找回决定覆盖。

## 收尾审查发现:决策"两源"不是重复,是两视图(勿硬删 enrichment.decisions)
审查"删 enrichment.decisions"时发现它被**深度绑定**且**与 A2 shape 不同**:
- **enrichment.decisions**:富格式 `{decision, problem, options, rationale, owner, turn_ids}`——**前端网关
  `meeting_result_adapter.py` 靠它渲染决策卡片**,另有 ~8 个评测脚本读它;
- **A2 summary.decisions**:精简 `{text, type, owner, refs}`——带 **type(decision/proposal)**,评测卖点 over 以此为准。
- → **两者是两个视图**(A2=纪律/评测口径;enrichment=前端富展示),**不是纯重复**;A2 修的架构病
  (summary.decisions 空)已修好。**直接删会断前端 + 评测,且 A2 不是 drop-in 替代。**

**已做(口径对齐)**:`conformance/judge_prompt.candidate_text_from` 优先取 summary.decisions(带 type),
无则回退 enrichment——**评测 over 现以 A2 为准**。`run_report` 已双口径(decisions_source.summary/enrichment)。
